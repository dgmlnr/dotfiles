# Hyprland per-host split — execution plan

Status: **planned, not executed**. Written 2026-07-19.

Machines sharing this repo:

| Host | Hardware | Role | Outputs |
|---|---|---|---|
| `hexdev` | AMD Polaris (RX 470/580) | remote-access **server** (VNC + Sunshine/Moonlight) | `DP-3` physical, `moonlight` headless at `3000x0` |
| `hexdev-home` | Intel i915 (Haswell) | remote-access **client** | `HDMI-A-1` (LG E2340, `0x0`), `eDP-1` (LG Display 0x03E9, `-1366x0`) |

## Target layout

```
dot_config/hypr/hyprland.conf.tmpl        common core + one include line
dot_config/hypr/host/hexdev.conf          server desktop
dot_config/hypr/host/hexdev-home.conf     laptop client
```

The template's only conditional is a single line near the end:

```
source = ~/.config/hypr/host/{{ .chezmoi.hostname }}.conf
```

One branch point instead of `{{ if }}` scattered through 331 lines. A mistake here
breaks the desktop, so the blast radius is kept to one statement.

## Common core

Header; `monitor = , preferred, auto, 1` (catch-all fallback — **keep first**, it is
the only thing that gives an unrecognised machine a usable output); `$terminal` /
`$fileManager` / `$menu`; `dbus-update-activation-environment`; `hyprpolkitagent`;
`waybar`; `wallpaper.sh`; `mako`; `keepassxc`; `cliphist` text+image; cursor theme
env vars; `GTK_IM_MODULE,simple`; `general{}`; `decoration{}`; `animations{}`;
`dwindle{}`; `misc{}`; `input{}`; `cursor{}`; `$mainMod`; all core binds; hjkl focus
and move; workspace switch/move 1-0; mouse workspace scroll and drag binds; cliphist
picker; screenshots; opacity binds; volume and brightness; the **passthrough submap**;
window rules for pavucontrol, nm-connection-editor, blueman, calculator, gsimplecal.

The passthrough submap stays shared deliberately — it is the *client* half of the
remote-desktop pair and matters more on the laptop than on the server.

## Per-host: `host/hexdev.conf`

`monitor = DP-3, preferred, 0x0, 1`; `monitor = moonlight, 1920x1080@60, 3000x0, 1`;
the chained `moonlight-display.sh init; hyprlock` autostart; `kwalletd6` (Smb4K work
shares); `wayvnc-keepalive.service`; `Sunshine.service`; `moonlight-watchdog.service`;
the commented `vnc-watch.sh`; `claude-remote` autostart + its window rule; `thunderbird`
autostart + its window rule; `env = AQ_NO_MODIFIERS,1`; the `panic-restore.sh` bind.

## Per-host: `host/hexdev-home.conf`

Monitors by stable description, **notebook first** (see risk R5):

```
monitor = desc:LG Display 0x03E9, 1366x768@60, -1366x0, 1
monitor = desc:LG Electronics E2340, 1920x1080@60, 0x0, 1
```

Workspace bindings 1-5 → external (ws1 `default:true`), 6-10 → notebook (ws6
`default:true`); `exec-once = hyprlock`; `exec-once = systemctl --user start
claude-remote.service`.

**Do NOT carry over**: `AQ_NO_MODIFIERS` (AMD-only; on i915 it forces linear buffers
and loses compression/tiling), any VNC/Sunshine/moonlight service, the `panic-restore`
bind, the `moonlight-display.sh init` autostart.

**Flip on this host**: enable `hypridle`. It is disabled on `hexdev` on purpose so the
box stays reachable, but a laptop needs idle-lock and screen-off.

## Blockers — must be handled with the split, not after

1. **`DP-3` is hardcoded inside scripts**, not only in the config: `lock.sh`,
   `idle-dpms.sh`, `wayvnc-keepalive.sh`, `moonlight-display.sh`,
   `moonlight-watchdog.sh`, `vnc-mode-off.sh`, `panic-restore.sh`. Splitting the
   `.conf` alone leaves `lock.sh` waking an output that does not exist on the laptop.
   Prefer auto-detection; the pattern already exists in `vnc-mode-on.sh`:
   `hyprctl monitors -j | jq -r '.[] | select(.name | startswith("HEADLESS") | not) | .name' | head -1`
2. **`input-settings.sh` rewrites `hyprland.conf` in place** (`kb_layout`,
   `natural_scroll`, `sensitivity`). Once the file is generated by chezmoi, those
   edits are destroyed on the next `apply`. Currently unbound, so it is latent — but
   it must be retargeted at the host file or removed as part of this work.
3. **`monitor-mode.sh` duplicates both monitor descriptions and their geometry**
   (`BIG_DESC`, `NB_DESC`, `BIG_ON`, `NB_LEFT`, `NB_ORIGIN`). Moving only the `.conf`
   lines leaves SUPER+P silently broken: `hyprctl keyword monitor` against a
   nonexistent description is a no-op, so the user gets a success notification and
   no change.
4. **`.chezmoiignore` must become templated** to keep the 7 server-only scripts off
   client machines.
5. **`packages/hexdev-home.txt` does not exist**; the README bootstrap hardcodes
   `packages/hexdev.txt`.
6. **`README.md` documents templating that was never implemented** and cites `DP-1`,
   which is not the real output name. Correct it so the docs stop describing a state
   that does not exist.

## Other risks worth fixing while in here

- `hyprland.conf` and `waybar/config.jsonc` hardcode `/home/<user>` in 14 places
  across 8 files. Waybar JSON cannot expand `$HOME`, so it needs template treatment.
- `dbus-update-activation-environment` and `herdr` resolve to Homebrew paths. If the
  common core reaches a machine without Homebrew on `PATH`, the dbus line fails and
  portals plus the polkit agent lose their Wayland environment — a much worse failure
  than a dead keybind. Consider pinning to `/usr/bin/`.
- `eDP-1` advertises only `1366x768@59.99Hz` while the config requests `@60`.
  Hyprland accepts it today; `preferred` would be safer.
- Negative-X monitor positioning is order-sensitive: the notebook must reach
  `-1366x0` before the external claims `0x0`, or the two briefly overlap and focus
  lands wrong.
- `hyprpaper.conf` is inert — `wallpaper.sh` applies the wallpaper over IPC because
  hyprpaper silently ignores its own config here. Annotate or delete it.
- `keybinds.sh` slices the selected row at a fixed column (`${selected:60}`) that
  depends on padding emitted by `keybinds.py`. Keep both files in the same tier.
- `blueman-manager` window rule targets a tool that is not installed; the waybar
  bluetooth module launches `overskride` instead.
- `gsimplecal, move 775 46` is a pixel offset derived from a 1920-wide primary with a
  44px bar. Host-specific in effect.
